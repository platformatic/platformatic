# @platformatic/composer

> **Deprecated.** This package was renamed to [`@platformatic/gateway`](../gateway) in v3.0.0. It is
> kept as an alias that re-exports Gateway so existing applications keep working, it logs a
> deprecation warning on startup, and **it will be removed in v4.0.0**. New applications should
> depend on `@platformatic/gateway` directly.

Platformatic Composer provides API composition capabilities for aggregating multiple applications. See [@platformatic/gateway](../gateway) for the full API gateway package.

Check out the full documentation on [our website](https://docs.platformatic.dev/docs/reference/gateway/overview).

## Install

```sh
npm install @platformatic/composer
```
